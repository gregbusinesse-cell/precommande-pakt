ÉTAPES SUIVANTES
================================================================================

ÉTAPE 1: CONFIGURER LE WEBHOOK STRIPE (IMPORTANT!)
Allez à: https://dashboard.stripe.com/webhooks
1. Cliquez "Add an endpoint"
2. URL: https://YOUR_VERCEL_DOMAIN/api/webhook
3. Events: payment_intent.succeeded
4. Copiez le Signing secret (commence par whsec_)
5. Ajoutez en variable Vercel: STRIPE_WEBHOOK_SECRET

ÉTAPE 2: VÉRIFIER LES VARIABLES D'ENV SUR VERCEL
Vercel Dashboard → Settings → Environment Variables
✓ STRIPE_SECRET_KEY (sk_test_...)
✓ STRIPE_WEBHOOK_SECRET (whsec_...)
✓ SENDGRID_API_KEY (SG_...)

ÉTAPE 3: TESTER LOCALEMENT (AVANT DÉPLOYER)
```bash
# Terminal 1
vercel dev

# Terminal 2
node test-webhook.js
```

ÉTAPE 4: TESTER EN PRODUCTION
1. Accédez à https://YOUR_VERCEL_DOMAIN/paiement.html
2. Testez avec 4242 4242 4242 4242
3. Vérifiez que l'email arrive
4. Vérifiez les logs: vercel logs --tail
